# Analizador de Llamadas — Banco MultiMoney

App web para evaluar el desempeño de asesores de ventas de créditos personales.

## Configuración en Vercel

1. Sube este proyecto a GitHub
2. Importa el repositorio en Vercel
3. Agrega la variable de entorno:
   - **Nombre:** `ANTHROPIC_API_KEY`
   - **Valor:** tu API key de Anthropic (sk-ant-...)
4. Deploy

## Uso

- Pega la transcripción de la llamada
- Haz clic en "Analizar Llamada"
- Descarga el PDF o copia el análisis
